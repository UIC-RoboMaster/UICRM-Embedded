## 电路

> 采用 双 DJI Robomaster C型开发板

### 以CAN 总线的思想看电机外设

***上 C 板***:
- CAN2:
    - yaw:      DM-J4310-2EC      1(电调 ID)    0x101(电调接收)    0x201(电调反馈)    `位置速度模式`, 位置环->速度环->电流环
    - pitch:    DM-J4310-2EC      2(电调 ID)    0x102(电调接收)    0x202(电调反馈)    `位置速度模式`, 位置环->速度环->电流环
    - 折叠轴电机: DM-J4310-2EC      3(电调 ID)    0x103(电调接收)    0x203(电调反馈)    `位置速度模式`, 位置环->速度环->电流环
    - 拨弹电机:  DM-J4310-2EC      4(电调 ID)    0x104(电调接收)    0x204(电调反馈)     `位置速度模式`, 位置环->速度环->电流环
    - 左摩擦轮:   M3508            5(电调 ID)    0x1FF(电调接收)    0x205(电调反馈)
    - 右摩擦轮:   M3508            6(电调 ID)    0x1FF(电调接收)    0x206(电调反馈)
- CAN1:
    - [can_bridge]


***下 C 板***:
- CAN1:
    - [can_bridge]
- CAN2:
    - 底盘 fl: M3508  1(电调 ID)    0x200(电调接收)   0x201(电调反馈)
    - 底盘 fr: M3508  2(电调 ID)    0x200(电调接收)   0x202(电调反馈)
    - 底盘 br: M3508  3(电调 ID)    0x200(电调接收)   0x203(电调反馈)
    - 底盘 bl: M3508  4(电调 ID)    0x200(电调接收)   0x204(电调反馈)

### 通信接口接线

**上 C 板**

| 板上接口 | 连接设备     |
| --- |----------|
| DBUS | Dbus 接收机 |
| UART2 | 裁判系统, UI数据 |
| UART1 | 图传模块     |
| USB | mini-PC  |
| SWD | 下载器, RTT |

**下 C 板**

| 板上接口 | 连接设备 / 用途 |
| --- | --- |
| SWD | 下载器、RTT 调试日志 |
